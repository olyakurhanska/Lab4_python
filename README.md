# Лабораторна робота №4

**Тема:** Створення графічного користувацького інтерфейсу з використанням PyQt6 в Python.

**Мета:** Навчитися створювати графічні інтерфейси в Python за допомогою бібліотеки PyQt6.

## Виконані завдання

1. **task1.py** — створення вікна з різними віджетами та їх розміщення.
2. **task2.py** — створення інтерактивної форми з перевіркою введених даних.
3. **task3.py** — створення головного вікна з меню, панеллю інструментів і рядком стану.
4. **task4.py** — реалізація взаємодії між компонентами за допомогою сигналів.
5. **task5.py** — створення діалогових вікон та оформлення інтерфейсу за допомогою QSS.

## Запуск програми

Для роботи необхідно встановити Python та бібліотеку PyQt6.

Встановлення бібліотеки:

`pip install PyQt6`

Запуск завдання:

`python task1.py`

Для інших завдань потрібно змінити номер файлу від 1 до 5.

## Висновок

У ході лабораторної роботи було створено п'ять програм із графічним інтерфейсом. Закріплено навички роботи з віджетами, сигналами, меню, діалоговими вікнами та стилізацією в PyQt6.
